# 비밀번호 금고 (macOS)

> ⚠️ **개인용으로 만든 앱입니다. 보안 감사를 받지 않았습니다.**
> 암호화는 표준 방식(PBKDF2-HMAC-SHA256 + AES-256-GCM)을 쓰고 RFC 시험값으로 검증했지만,
> 제3자의 보안 감사를 받은 적이 없습니다. 지켜 주는 것과 못 지키는 것은
> [안전 장치 설명](#안전-장치-설명)에 솔직히 적어 두었습니다. 읽고 판단해 주세요.

1Password 처럼 **마스터 비밀번호 하나로 나머지 비밀번호를 전부 지키는** 맥용 앱입니다.
계정 가입도, 구독료도, 서버도 없습니다. 비밀번호는 이 맥 안의 **암호화된 파일 하나**에만 들어 있습니다.

| | |
| --- | --- |
| **필요한 것** | macOS 13(벤투라) 이상. 인텔·애플실리콘 모두 지원 |
| **설치** | zip 받아서 `응용 프로그램`으로 끌어 놓기 |
| **자료 보관 위치** | `~/Library/Application Support/PasswordVault/vault.pvault` |
| **암호화** | PBKDF2-HMAC-SHA256(60만 회 이상) + AES-256-GCM |

---

## 먼저 알아 두실 점

1Password 를 완전히 대체하지는 **못합니다.** 없는 기능을 미리 말씀드립니다.

| 1Password 에 있는 것 | 이 앱 |
| --- | --- |
| 브라우저에서 자동 입력 | 크롬만 됩니다([붙이기](#브라우저-자동완성-크롬)). 사파리는 복사(⇧⌘C)해서 붙여넣으세요 |
| 여러 기기 동기화 | **없습니다.** 파일을 직접 옮기거나 클라우드 폴더에 두셔야 합니다 |
| 가족·팀 공유 | 없습니다 |
| Touch ID 로 잠금 해제 | 없습니다. 마스터 비밀번호를 직접 칩니다 |
| 유출된 비밀번호 검사(온라인 조회) | 없습니다. 대신 **약한 비밀번호·재사용한 비밀번호**는 앱 안에서 찾아 줍니다 |

있는 것은 이렇습니다.

- 마스터 비밀번호 하나로 전체 잠금·해제
- 로그인 / 보안 메모 / 카드 항목, 사용자 지정 필드, 태그, 즐겨찾기
- 검색(제목·아이디·주소·태그. **비밀번호 값 자체는 검색되지 않습니다**)
- 비밀번호 생성기 (무작위 문자 / 외우기 쉬운 단어 조합)
- 2단계 인증(OTP) 코드 생성 — `otpauth://` 주소나 Base32 시크릿을 넣으면 30초마다 코드를 보여 줍니다
- 자동 잠금(기본 5분), 잠자기·화면 잠금 시 잠금
- 복사한 비밀번호 자동 지우기(기본 30초)
- 약한 비밀번호 · 재사용한 비밀번호 찾기
- 크롬·사파리·1Password·Bitwarden CSV 가져오기, 암호화 백업 저장
- 크롬 자동완성(확장 설치, 아래 참고)

## 1단계: 받아서 설치

1. [최신 릴리스](../../releases/tag/password-vault-latest)에서 **`PasswordVault-macOS.zip`** 을 받습니다.
2. 압축을 풀고 `PasswordVault.app` 을 **`응용 프로그램` 폴더로 끌어 놓습니다.**
3. 처음 열 때 **마우스 오른쪽 클릭 → 열기 → 열기** 를 누릅니다.

> **"확인되지 않은 개발자" 또는 "손상되었기 때문에 열 수 없습니다" 라고 나오면?**
>
> 애플 개발자 계정(연 12만 원)으로 공증받지 않은 앱이라 나오는 경고입니다.
> 오른쪽 클릭 → 열기로도 안 되면 **터미널**(`응용 프로그램 → 유틸리티 → 터미널`)에서 아래를 한 번 실행하고 다시 여세요.
>
> ```sh
> xattr -dr com.apple.quarantine /Applications/PasswordVault.app
> ```
>
> 이 명령은 "인터넷에서 받은 파일" 이라는 표시를 떼는 것으로, 앱을 바꾸지는 않습니다.
> 찜찜하시면 아래 [직접 빌드하기](#직접-빌드하기)로 소스에서 직접 만들어 쓰셔도 됩니다.

## 2단계: 금고 만들기

처음 실행하면 **마스터 비밀번호**를 정하는 화면이 나옵니다.

- 이 비밀번호는 **어디에도 저장되지 않습니다.** 잊어버리면 금고를 여는 방법이 없습니다.
  (그래서 안전합니다. 만드는 회사도 열 수 없습니다.)
- **8자 이상**이어야 하고, 길수록 좋습니다.
- 무엇으로 할지 막막하면 **`외우기 쉬운 비밀번호 제안받기`** 를 누르세요.
  `river-candle-forest-magnet-piano-tunnel` 같은 여섯 단어 조합을 만들어 줍니다.
  이런 형태가 `P@ssw0rd!` 보다 외우기 쉽고 **훨씬** 안전합니다.
- 종이에 적어 지갑이나 서랍에 두는 것도 나쁜 방법이 아닙니다.
  이 앱을 노리는 건 인터넷 너머의 공격자이지, 집에 들어온 사람이 아닙니다.

## 3단계: 쓰는 법

### 항목 넣기

`⌘N` 또는 툴바의 **+**. 제목·아이디·비밀번호·주소를 넣고 저장합니다.
비밀번호 칸 옆의 **지팡이 단추**를 누르면 그 자리에서 새 비밀번호를 만들어 넣을 수 있습니다.

### 꺼내 쓰기

| 하고 싶은 것 | 방법 |
| --- | --- |
| 비밀번호 복사 | 항목 고르고 **⇧⌘C** (또는 비밀번호 옆 복사 단추) |
| 아이디 복사 | **⇧⌘B** |
| 웹사이트 열기 | **⇧⌘O** |
| 검색 | **⌘F** 또는 목록 위 검색창 |
| 지금 잠그기 | **⌘L** |
| 비밀번호 생성기 | **⇧⌘G** |
| 설정 | **⌘,** |

복사한 비밀번호는 **30초 뒤 클립보드에서 자동으로 지워집니다**(설정에서 변경 가능).
그 사이 다른 것을 복사했다면 건드리지 않습니다.

### 2단계 인증(OTP)

구글·깃허브 등에서 2단계 인증을 켤 때 QR 코드 대신 **"수동으로 입력"** 을 누르면
`JBSWY3DPEHPK3PXP` 같은 문자열이 나옵니다. 그 값을 항목 수정 화면의 **인증 코드** 칸에 붙여넣으세요.
그 뒤로는 항목을 열 때마다 30초마다 바뀌는 6자리 코드가 보입니다.

> 같은 기기에 비밀번호와 2단계 인증을 함께 두면 2단계 인증의 의미가 줄어듭니다.
> 은행처럼 특히 중요한 곳은 휴대폰의 별도 앱에 두는 편이 안전합니다.

### 점검

사이드바의 **약한 비밀번호 / 재사용한 비밀번호** 를 눌러 보세요.
짧거나 흔한 비밀번호, 여러 사이트에서 돌려 쓰는 비밀번호를 모아서 보여 줍니다.
재사용이 위험한 이유는, 한 사이트가 털리면 같은 비밀번호를 쓴 나머지도 함께 뚫리기 때문입니다.

## 브라우저 자동완성 (크롬)

크롬에서 로그인 칸을 누르면 저장해 둔 아이디·비밀번호가 목록으로 뜨고, 고르면 채워집니다.
크롬 자체 자동완성과 비슷하지만 비밀번호는 이 금고에만 있습니다.

### 붙이기 (한 번만)

```sh
./Scripts/install-autofill.sh
```

그리고 크롬에서 확장을 한 번 넣어 줍니다.

1. 주소창에 `chrome://extensions` 붙여넣기
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 저장소의 `extension` 폴더 고르기

떼려면 `./Scripts/install-autofill.sh --uninstall` 을 실행하고 크롬에서 확장을 지우면 됩니다.

### 쓰는 법

금고 앱을 열어 **잠금을 풀어 두면** 됩니다. 로그인 칸을 누를 때 목록이 뜹니다.
잠겨 있으면 "금고가 잠겨 있습니다" 라고만 알려 줍니다.

### 무엇을 지키는가

- **잠겨 있으면 아무것도 내주지 않습니다.** 키가 메모리에 없어서 읽을 수조차 없습니다.
- 금고 전체를 넘기지 않습니다. **지금 보고 있는 주소에 해당하는 항목만** 보냅니다.
- 주소는 페이지 말을 믿지 않고 **크롬이 알려 주는 실제 주소**를 씁니다.
- 짝짓기는 호스트가 정확히 같거나 하위 도메인일 때만 됩니다.
  `github.com` 에 저장한 비밀번호는 `github.com.evil.com` 으로 **절대 넘어가지 않습니다**
  (이 경우들은 시험으로 고정해 두었습니다).
- **저절로 채우지 않습니다.** 목록에서 직접 고를 때만 값이 들어갑니다.
  보이지 않는 가짜 로그인 폼으로 자동완성을 낚아채는 수법을 막기 위해서입니다.
- 폼을 대신 제출하지 않습니다. 확인은 사람이 합니다.
- 앱과 확장은 내 계정만 열 수 있는 소켓(`0600`)으로만 이야기합니다. 인터넷을 쓰지 않습니다.
- 설정 → 보안 → **브라우저 자동완성 허용** 을 끄면 통로 자체가 닫힙니다.

## 다른 앱에서 옮겨 오기

설정(`⌘,`) → **가져오기·내보내기** → **CSV 파일 고르기**.

내보내는 방법은 앱마다 다릅니다.

| 원래 쓰던 곳 | 내보내는 곳 |
| --- | --- |
| 크롬 | 설정 → 자동 완성 → 비밀번호 관리자 → ⋮ → 비밀번호 내보내기 |
| 사파리 | 설정 → 비밀번호 → ⋯ → 모든 비밀번호 내보내기 |
| 1Password | File → Export → CSV |
| Bitwarden | 도구 → 보관함 내보내기 → .csv |

가져오기 전에 **미리 보기 화면**이 뜹니다. 어떤 열을 제목·아이디·비밀번호로 읽었는지 확인할 수 있고,
이미 있는 항목은 자동으로 건너뜁니다.

> ⚠️ **내보낸 CSV 파일에는 비밀번호가 그대로 적혀 있습니다.**
> 다 옮기셨으면 그 파일을 지우고 휴지통도 비우세요.

## 백업

설정 → 가져오기·내보내기 → **백업 파일 저장**.

금고 파일을 **암호화된 그대로** 복사합니다. 그래서 iCloud Drive·구글 드라이브·외장 디스크
어디에 둬도 됩니다. 복원할 때는 그 파일을 원래 위치에 되돌려 놓거나,
설정 → 금고 → **다른 금고 파일 열기** 로 지정하면 됩니다. 물론 그때도 마스터 비밀번호가 필요합니다.

앱은 저장할 때마다 직전 내용을 `vault.pvault.bak` 으로 한 벌 남겨 둡니다.

## 안전 장치 설명

솔직하게, 무엇을 지켜 주고 무엇은 못 지키는지 적습니다.

**지켜 주는 것**

- 금고 파일을 통째로 가져가도 마스터 비밀번호 없이는 열 수 없습니다.
  키는 PBKDF2-HMAC-SHA256 을 **60만 회 이상**(기기 속도에 맞춰 자동 조정) 돌려 만듭니다.
  무차별 대입을 아주 느리게 만들기 위해서입니다.
- 내용은 AES-256-GCM 으로 암호화합니다. 인증 태그가 붙어 있어 **한 바이트라도 바뀌면 열리지 않습니다.**
- 파일 머리말(반복 횟수·솔트)까지 인증 범위에 넣었습니다.
  공격자가 "반복 횟수 1회" 짜리로 바꿔치기해 크래킹을 쉽게 만드는 수법을 막습니다.
- 금고 파일 권한은 `600` 입니다. 같은 맥의 다른 사용자 계정이 읽을 수 없습니다.
- 잠그면 메모리에서 키와 항목을 버립니다.
- 클립보드에 올릴 때 "비밀 값" 표시를 붙여, 이를 이해하는 클립보드 관리자들이 기록을 남기지 않게 합니다.

**못 지키는 것 (알고 쓰셔야 합니다)**

- **이미 감염된 맥.** 키로거나 화면 캡처 악성코드가 깔려 있으면 어떤 비밀번호 앱도 소용없습니다.
- **잠금 해제된 상태.** 금고가 열려 있는 동안에는 화면에 값이 보입니다. 자리를 뜨실 땐 `⌘L`.
- **마스터 비밀번호 분실.** 복구 수단이 **없습니다.** 이건 결함이 아니라 설계입니다.
- **메모리 덤프.** 열려 있는 동안 키는 메모리에 있습니다. 스위프트에서 완전한 삭제는 보장할 수 없습니다.
- 애플 공증(notarization)을 받지 않았습니다. 그래서 첫 실행 때 경고가 뜹니다.

## 직접 빌드하기

Xcode 앱 전체는 필요 없고 **명령줄 도구**만 있으면 됩니다.

```sh
xcode-select --install          # 아직 없다면

git clone https://github.com/SoojiNoh/password-vault.git
cd password-vault

swift test                      # 단위 검사 (약 1분)
./Scripts/build-app.sh          # build/PasswordVault.app 생성
open build/PasswordVault.app
```

`build-app.sh` 는 인텔·애플실리콘 겸용으로 빌드하고, 아이콘을 만들어 넣고, 임시 서명을 한 뒤
**자체 검사(`--selftest`)를 통과해야만** 성공으로 끝냅니다.
이 맥의 CPU 용으로만 빠르게 만들려면 `./Scripts/build-app.sh --native`.

### 구조

```
password-vault/
├── Sources/
│   ├── VaultCore/          # 화면과 무관한 로직 — 전부 시험 대상
│   │   ├── VaultCrypto     # 키 파생(PBKDF2) · 암복호화(AES-GCM)
│   │   ├── VaultFile       # 파일 형식 · 원자적 저장 · 백업
│   │   ├── VaultModel      # 항목 자료구조 (예전 파일도 열리게 관대하게 해석)
│   │   ├── PasswordGenerator / PasswordStrength / WordList
│   │   ├── TOTP            # RFC 4226 / 6238
│   │   ├── CSVSupport      # RFC 4180 파서 + 열 이름 추측
│   │   ├── AutofillMatch   # 주소 ↔ 항목 짝짓기 (가짜 도메인 차단)
│   │   └── SelfTest        # 배포 전 관문으로 쓰는 검사 모음
│   └── PasswordVault/      # SwiftUI 화면
│       └── AutofillBridge  # 크롬 확장과 잇는 소켓 · 네이티브 메시징
├── extension/              # 크롬 확장 (manifest v3)
└── Tests/VaultCoreTests/   # XCTest
```

명령줄 옵션:

```sh
PasswordVault.app/Contents/MacOS/PasswordVault --selftest   # 창 없이 자체 검사
PasswordVault.app/Contents/MacOS/PasswordVault --version
PasswordVault.app/Contents/MacOS/PasswordVault --native-host  # 크롬이 직접 띄우는 모드
```

## 자주 묻는 것

**Q. 마스터 비밀번호를 잊었습니다.**
방법이 없습니다. 백업 파일이 있어도 같은 비밀번호가 필요합니다.
금고를 지우고 새로 시작하려면 `~/Library/Application Support/PasswordVault/` 폴더를 지우세요.
(그 안의 비밀번호는 전부 사라집니다.)

**Q. 아이폰에서도 쓰고 싶습니다.**
이 앱은 맥 전용입니다. iCloud Drive 안에 금고 파일을 두면 다른 맥에서는 쓸 수 있지만,
두 대에서 **동시에** 고치면 나중에 저장한 쪽이 이깁니다.

**Q. 창을 닫으면 종료되나요?**
네. 종료하면 당연히 잠깁니다. 잠깐 자리를 비울 때는 `⌘L`.

**Q. 자동 잠금이 너무 자주/드물게 걸립니다.**
설정(`⌘,`) → 보안 → 자동 잠금. 사용 안 함부터 1시간까지 고를 수 있습니다.

**Q. 비밀번호가 회사 규정(대문자·숫자·특수문자 포함, 16자 이하 등)에 안 맞습니다.**
생성기(`⇧⌘G`)에서 길이와 문자 종류를 조절하세요.
`헷갈리는 글자 빼기` 를 켜면 `0/O`, `1/l/I` 를 뺍니다. 옮겨 적어야 할 때 유용합니다.

**Q. 금고 파일을 열어 봤더니 알아볼 수 없는 글자뿐입니다.**
정상입니다. 그게 암호화된 상태입니다.
